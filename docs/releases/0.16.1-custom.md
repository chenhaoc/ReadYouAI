# ReadYou 0.16.1-custom

上游基线版本：`0.16.1`

本文档用于持续记录基于上游 `0.16.1` 演进的个人定制发行线。

## 0.16.1-custom.8

这一版在 `0.16.1-custom.7` 基础上，重点补齐离线同步保护、AI 多配置与联网搜索能力，并继续打磨 TTS 播放、翻译渲染和阅读页浏览体验。

来源说明：

- 本版没有引入新的上游 PR，主要为 `ReadYouAI` 本地定制改动

新增功能：

- 增加 AI 多配置管理能力，可新增、复制、删除、切换并测试多套 AI 服务配置
- 增加 AI 问答联网搜索能力，优先通过 Responses API 调用 `web_search` 工具获取外部信息
- 增加 AI 设置页联网搜索测试入口，可直接验证当前模型配置是否支持联网搜索
- 增加 TTS 播放列表文章日期展示，补齐收听队列中的时间信息

稳定性修复：

- 修复离线使用后的同步状态回写问题，减少已读和星标状态在恢复联网后被意外覆盖的情况
- 修复部分 AI 服务的连接检测兼容性问题，减少明明可用却被误判失败的情况

体验优化：

- 优化 TTS 播放完成后的进度处理，完播后会清空当前进度，便于直接重播同一篇文章
- 优化单栏阅读返回列表时的位置保持，减少来回进出文章后的定位丢失
- 修复阅读页摘要卡片压住正文的问题，这一版补齐了 `custom.7` 未完全解决的剩余场景
- 修复 WebView 阅读模式下译文可能不显示的问题，减少切换阅读模式后的内容缺失
- 统一 WebView 和 native 阅读模式下的译文显示风格，减少颜色、间距和列表着色上的割裂感
- 调整 AI 配置与备份相关文案，使配置管理、导入导出和密钥提示更清晰

## 0.16.1-custom.7

这一版在 `0.16.1-custom.6` 基础上，重点升级后台 AI 摘要预生成、TTS 摘要模式播放和媒体控制稳定性，并补齐 AI 服务诊断、阅读页 WebView 稳定性与 `ReadYouAI` 品牌资源。

来源说明：

- 本版没有引入新的上游 PR，主要为 `ReadYouAI` 本地定制改动

新增功能：

- 增加后台 AI 摘要预生成链路，可在同步后为开启自动摘要的订阅源预生成新文章摘要
- 增加历史未读摘要补齐能力，支持同步后自动补齐，也支持在 AI 设置页手动触发
- 增加每次最多预生成篇数设置，可限制后台 AI 调用规模，也可设为不限
- 增加 TTS 摘要模式，可按选定分组和订阅源生成面向收听的摘要播放列表
- 增加摘要模式的 AI 推荐生成，可由 AI 从摘要候选中挑选更适合播放的文章，失败时回退为最新优先
- 增加播放卡片和通知栏收藏入口，播放时可直接切换当前文章收藏状态
- 增加 AI 服务测试连接入口，使用当前 API 地址、API Key 和模型快速验证可用性

体验优化：

- 将播放面板切换统一为“全文模式 / 摘要模式”，补齐摘要列表生成、空态、重新生成确认和生成中提示
- 稳定蓝牙耳机和通知栏媒体键控制，提升 TTS 播放、暂停和切换在后台播放时的可靠性
- 优化 native 阅读页摘要展开跳转与可见性判定，减少跳转后正文短暂重叠和摘要卡误判问题
- 修复 WebView 阅读模式下摘要卡片压住正文的问题，使 WebView 正文滚动与外层阅读页滚动保持一致
- 优化 AI 设置页结构，将模型服务、摘要、翻译和问答分区展示，配置路径更清晰
- 优化 AI Base URL 默认值和规范化逻辑，减少空值或地址格式不一致造成的请求失败
- 优化 `ReadYouAI` 启动图标，改用矢量前景并提升小尺寸辨识度

配套改动：

- 增加后台摘要任务表、退避重试字段和数据库 schema 迁移，避免摘要失败阻塞同步链路
- 按账号隔离同步后置任务和缓存清理，降低多账户场景下摘要、同步和缓存串用风险
- 修正备份导出的偏好默认值，并移除残留导出项
- 按 flavor 固定更新检查地址，使 `githubAi` 指向 `ReadYouAI` 发布页
- 补充后台摘要、摘要模式和 TTS 媒体控制相关设计文档与单元测试

## 0.16.1-custom.6

这一版在 `0.16.1-custom.5` 基础上，继续围绕 TTS 播放体验、阅读页支持入口与 `ReadYouAI` 品牌一致性做了一轮整合优化。

新增功能：

- 增加 `githubAi` flavor 的更新检查，并支持 `custom.N` 版本比较
- 增加 TTS 对通知栏媒体控制和蓝牙耳机标准媒体按键的支持
- 增加悬浮播放列表按钮上下拖动与吸边能力，移动入口位置时更顺手
- 清洗本地 RSS 和兼容来源中的视频控件噪音，减少正文阅读和 TTS 朗读中的干扰文本

体验优化：

- 优化 TTS 播放控制路径，使通知栏与耳机按键可以参与当前文章的播放、暂停与切换
- 优化 TTS 前台通知样式，补齐应用大图标，提升播放状态识别度
- 优化阅读页 AI 问答初始化与渲染路径，降低进入文章后查看问答的等待感
- 优化 native 模式下的摘要跳转行为，使跳转位置更符合预期
- 优化译文块与原文的样式一致性，减少双语阅读时的割裂感
- 优化提示与支持页内容，补充版本信息、仓库与文档、发布说明、开源许可证、支持方式和特性概览等区块

配套改动：

- 更新 `githubAi` flavor 的应用名称、启动图和桌面图标，统一 `ReadYouAI` 品牌资源
- 补齐备份恢复字段，降低配置迁移和恢复时的丢项风险

## 0.16.1-custom.5

这一版在 `0.16.1-custom.4` 基础上，补齐了阅读页 AI 问答能力，并把问答回复的展示从简单文本升级为更完整的 Markdown 渲染。

新增功能：

- 增加阅读页 AI 问答入口与问答抽屉
- 增加问答会话存储与历史保留
- 增加 AI 提示词配置能力，统一摘要、翻译与问答的提示词编辑入口
- 增加基于 WebView 的 Markdown 回复渲染，支持更完整的富文本展示

交互变化：

- 优化问答抽屉的展示与发送交互，降低使用摩擦
- 优化问答历史在阅读流程中的保留策略，减少意外丢失
- 优化 Markdown 回复的排版与样式表现，使长回复更易读

配套改动：

- 为嵌入式 WebView 内容增加高度回传能力，支撑阅读页中的问答回复布局
- 按功能粒度整理 AI 问答相关的本地提交历史，便于后续继续维护

新增功能：

交互变化：

- 优化后台恢复播放表现，使续播更连贯
- 调整阅读时长估算速度，使展示结果更贴近实际体验
- 将根级播放列表改为模态底部面板，返回时优先关闭播放列表

配套改动：

## 0.16.1-custom.3

这一版在 `0.16.1-custom.2` 基础上，补充了完整的 TTS 播放列表能力，并把播放控制从单点按钮扩展为贯穿列表页、阅读页和全局悬浮入口的一整套流程。

新增功能：

- 增加 TTS 播放列表，可以将文章加入队列后连续播放
- 增加队列控制能力，支持立即播放、停止、跳转上一条/下一条、清空列表和队列内排序调整
- 增加阅读页播放进度与播放列表视图，补齐队列状态展示
- 增加全局悬浮播放按钮和根级播放列表抽屉，弱化“必须进入当前文章页才能控制播放”的限制

交互变化：

- 阅读页的 TTS 入口从单次朗读扩展为“加入播放列表 / 立即播放”等更完整的操作路径
- 订阅页与信息流页也补齐了播放列表入口和预览，浏览过程中可以更早组织播放队列
- 播放状态在页面间切换时更连续，当前播放项、进度和控制操作不再局限在单一页面
- 补充了悬浮播放器相关开关与中英文文案，使播放入口更直观

配套改动：

- 增加 TTS 队列控制器、适配层和对应测试
- 补充这一轮 TTS 播放列表相关的设计文档、计划文档与状态测试

## 0.16.1-custom.1

这一版对应此前标记为 `0.16.1.1` 的那组定制改动，也是整条 `0.16.1-custom` 分支的起点。

该版本以 PR [#1210](https://github.com/ReadYouApp/ReadYou/pull/1210) “Add AI article summarization feature”为基础，并在其上继续做了本地定制。

感谢 `jcrabapple` 提供原始 PR 与实现。

原 PR 提供的核心功能：

- 为文章增加 AI 摘要能力
- 增加摘要相关的 OpenAI 接入基础和设置项
- 在阅读页接入摘要入口和摘要生成流程

在此基础上的定制修改：

- 增加内联自动摘要流程，减少手动触发成本
- 统一摘要的多个触发入口，并补充加载反馈与自动展开策略
- 修复阅读页摘要交互、WebView 深色文字显示和摘要跳转返回等问题
- 增加应用配置的备份与恢复能力，并补齐导入导出的后续修正
- 补充 AI 摘要与备份恢复相关的简体中文文案
- 调整本地构建脚本和发布辅助流程

技术影响：

- 引入了与摘要、备份恢复以及后续翻译能力相关的数据库结构调整

说明：

- `0.16.1-custom.1` 仍由对应的 release-note 锚点提交和 tag 标记
- 后续 `0.16.1-custom.N` 版本继续在本文件中顺序追加维护
